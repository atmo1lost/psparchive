# installing custom Firmware

custom firmware (CFW) unlocks homebrew, plugins, and ISO loading on your PSP.

## 1. check your firmware version

go to **Settings > System Information** and note your current firmware version.

## 2. Pick the right CFW

| PSP model | recommended CFW |
|-----------|------------------|
| 1000/2000/3000 | ARK5 or ARK4 |
| PSP Go | ME |

## 3. download

Ark5: [here](https://github.com/PSP-Arkfive/FasterARK/releases/tag/latest)<br>
Ark4: [here](https://github.com/PSP-Archive/ARK-4/releases/tag/v42069r206)<br>
Me: [here](https://www.gamebrew.org/wiki/PRO_Firmware_PSP)<br>

## 4. install

```
1. copy the CFW installer to /PSP/GAME/ on your memory stick
2. (for ark5) copy whatever SAVEDATA is in the cfw (copy to /SAVEDATA)
3. run it from the XMB game menu
4. follow on-screen prompts
5. reboot when done
```

## 4. verify

check **Settings > System Information** again, you should see the CFW version listed alongside the firmware version.

> if the install fails partway through, dont panic, don't pull the battery. google it
