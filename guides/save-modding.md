# Save Modding Basics

Modifying save files for supported games, cheats, unlocks, edited stats.

## 1. Extract the save

Use a save manager homebrew to decrypt and extract the save from your memory stick.

## 2. Edit

Open the extracted save in a hex editor or a game-specific save editor if one exists.

## 3. Re-encrypt and reinject

Re-encrypt the save with the same tool and copy it back to the memory stick in the original location.

## 4. Test

Boot the game and confirm the save loads without corruption before doing anything critical.
